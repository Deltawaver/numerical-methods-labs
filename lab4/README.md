# Лабораторная 4, вариант 8

Запуск из этой папки
python lab4_1_cauchy.py
python lab4_2_boundary.py

Можно указать файл данных первым аргументом и шаг вторым.
Формат data4.1.txt — a b h y(a) y'(a).
Формат data4.2.txt — a b h значение_левой_границы значение_правой_границы.

4.1 реализует явный Эйлер, классический RK4 и явный Адамс–Башфорт
четвёртого порядка. Первые три шага Адамса вычисляются RK4.
В таблицах приведены ошибки основного шага и оценки Рунге–Ромберга
для мелкой сетки h/2. Порядки методов равны 1, 4, 4 соответственно.

4.2 имеет особенность. В уравнении (2x+1)y''+4xy'-4y=0
старший коэффициент обращается в ноль при x=-0.5.
Ищем гладкое продолжение через эту точку, согласованное с точным решением
из задания. Дифференцирование уравнения даёт (2x+1)(y'''+2y'')=0.
Для гладкого решения можно интегрировать y'=z, z'=w, w'=-2w.
Начальное w вычисляется из исходного уравнения при x=-2.
Стрельба подбирает y(-2), используя левое условие y'(-2)+2y(-2)=-9,
и обнуляет невязку правого условия y'(0)=1.
Линейная зависимость невязки от параметра позволяет найти его одним
шагом секущей после двух пробных траекторий. Точное решение в подборе
параметра не используется.

Конечные разности применяются к исходному уравнению без деления на 2x+1.
Граничные производные аппроксимируются односторонними формулами второго
порядка. Система решается LU-разложением с выбором главного элемента
из первой лабораторной. Из-за особой точки ошибка на грубой сетке
существенна. Оценка Рунге–Ромберга является асимптотической.
